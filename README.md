# AutoAid – Vehicle Breakdown Assistance System

AutoAid is a web-based system that helps drivers request roadside assistance when their vehicle breaks down.

The system connects users with nearby mechanics in real time.

## Features

User Features
- Register and login
- Submit vehicle breakdown request
- Share location
- View request status

Mechanic Features
- View nearby requests
- Accept service requests
- Navigate to customer location

Admin Features
- Monitor all requests
- Assign mechanics
- View system dashboard

## Technologies Used

Frontend

Backend

Tools
- Thunder Client

## How to Run

1. Install dependencies

npm install

2. Start server

node server.js

3. Open browser

http://localhost:3000

## Project Purpose

This project was developed as part of a university internship project to demonstrate a real-time vehicle breakdown assistance platform.
